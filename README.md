# Minimalistic volume control extension

Минималистичное расширение для управления громкостью аудио и видео в браузере.

## Возможности

- Регулировка громкости от 0% до 200%
- Быстрое отключение звука (Mute/Unmute)
- Сброс к 100%
- Предустановленные значения: 25%, 50%, 100%, 150%, 200%
- Отображение в процентах или децибелах
- Настраиваемый акцентный цвет

## Установка

### Chromium / Chrome

1. Откройте `chrome://extensions/`
2. Включите **Режим разработчика**
3. Нажмите **Загрузить распакованное расширение**
4. Выберите папку с файлами расширения

### Brave

1. Откройте `brave://extensions/`
2. Включите **Режим разработчика**
3. Нажмите **Загрузить распакованное расширение**
4. Выберите папку с файлами расширения

## Требования

- **Chromium 88+**
