# Minimalistic volume control extension

Минималистичное расширение для управления громкостью аудио и видео в браузере.

## Возможности

- Регулировка громкости от 0% до 200%
- Быстрое отключение звука (Mute/Unmute)
- Сброс к 100%
- Предустановленные значения: 25%, 50%, 150%, 200%
- Отображение в процентах, десятичной дроби или децибелах
- Настраиваемый акцентный цвет

## Установка

### Chromium-based browsers

1. Откройте `chrome://extensions/`
2. Включите **Режим разработчика**
3. Нажмите **Загрузить распакованное расширение**
4. Выберите папку с файлами расширения

### Firefox

1. Откройте `https://addons.mozilla.org/firefox/addon/volume-control-astalunavortex/`
2. Нажмите **Добавить в Firefox**

## Требования

- **Chromium 88+**
- **Firefox 142+**
